Picker Bridge Example

A provider picker page should call window.opener.postMessage(...) with this shape: 

{
  source: "tinymce-multicloud-plugin",
  type: "picked",
  providerId: "googleDrive",
  payload: {
    item: {
      id: "file-123",
      name: "Architecture.png",
      url: "https://example.com/Architecture.png",
      embedUrl: "https://example.com/embed/file-123"
    },
    mode: "image"
  }
}
