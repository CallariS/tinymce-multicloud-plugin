Privacy Policy

Last Updated: April 25, 2026

Overview

The TinyMCE MultiCloud Plugin ("the Plugin") is an open-source browser extension for the TinyMCE editor that enables users to select files from cloud storage providers (Google Drive, OneDrive, Dropbox, etc.) and insert them into editor content.

Data Collection and Usage

We do not collect, store, or transmit any personal data.

  • The Plugin runs entirely in your browser (client-side)
  • No data is sent to our servers (we don't have any servers)
  • No analytics, tracking, or telemetry is performed
  • No cookies are set by the Plugin

Cloud Provider Integration

When you use the Plugin to access files from cloud providers:

  • OAuth Authentication: You authenticate directly with the cloud provider (Google, Microsoft, Dropbox, etc.) using their official OAuth flow. The Plugin never sees your password.
  • Access Tokens: OAuth tokens are stored temporarily in your browser's memory and are not persisted.
  • File Selection: When you select a file, only the file metadata (name, URL, thumbnail) is passed to the TinyMCE editor. The actual file content is not accessed.
  • Direct Communication: Your browser communicates directly with the cloud provider's APIs. No data passes through our servers.

Permissions Requested

The Plugin requests the following permissions from cloud providers:

  • Google Drive: Read-only access to view and select files from your Drive
  • OneDrive: Read-only access via the OneDrive Picker API
  • Dropbox: Read-only access via the Dropbox Chooser API

These permissions are used only to display the file picker and retrieve public URLs for selected files. The Plugin cannot modify, delete, or download your files.

Third-Party Services

The Plugin integrates with third-party cloud storage providers. Each provider has their own privacy policy:

  • Google Privacy Policy
  • Microsoft Privacy Statement
  • Dropbox Privacy Policy

Open Source

The Plugin is open source and available on GitHub: github.com/CallariS/tinymce-multicloud-plugin

You can review the source code to verify that no data collection occurs.

Children's Privacy

The Plugin does not knowingly collect any personal information from anyone, including children under 13.

Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Updates will be posted on this page with a new "Last Updated" date.

Your Data Rights

Since we don't collect any data, there is no data to access, export, or delete. All interactions happen directly between your browser and the cloud provider you choose.
